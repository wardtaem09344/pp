# APEX Agent

تطوير مستودع `mmm` من حزمة واجهة فقط إلى تطبيق يتضمن خادمًا فعليًا وخطط استخدام ووكيلًا متكيفًا مع أدوات وذاكرة واختبارات.

## ما الذي تغيّر؟

- **الخادم:** FastAPI، تسجيل حسابات وتسجيل دخول، كلمات مرور scrypt، جلسات مخزّنة كبصمات، عزل بيانات الحسابات، إدارة المالك.
- **الخطط:** Free وPlus وPro وUltra؛ تُطبّق الحصص والصلاحيات على الخادم، وليس عبر إخفاء الأزرار فقط.
- **الوكيل:** توجيه عربي/إنجليزي متعدد المجالات، استراتيجيات قابلة للتكيّف، استدعاءات أدوات فعلية، نتائج موثقة، تقييم تنفيذ، وحالات توقف صريحة.
- **المهام الطويلة:** نقاط استئناف محفوظة، إلغاء، مخطط تبعيات محفوظ، وحدود للخطوات والتزامن والوقت.
- **الذاكرة:** ذاكرة تفضيلات ومشروع وملاحظات إجرائية محدودة، مع موافقة صريحة وعزل وحذف؛ لا تعديل ذاتي لتعليمات النظام.
- **الواجهة:** الاحتفاظ بالتصميم واللغتين، مقارنة الخطط والاستخدام، مراقبة المهام والأدلة، إدارة الذاكرة، وتعيين الخطط للمالك.
- **المزوّدات:** Gemini الأصلي مع اكتشاف نماذج توليد النصوص، ai-seek وفق الاتصال الذي قدمه المالك، وموصّل OpenAI-compatible اختياري.
- **التحقق:** اختبارات انحدار للخادم والأدوات والحصص والتوجيه والمزوّدات، مع فصل واضح بين الاختبارات المحلية والمكالمات الحية.

## التشغيل محليًا

يتطلب Python 3.11 أو أحدث.

```bash
python -m venv .venv
. .venv/bin/activate
pip install -r requirements-dev.txt
# أدخل إعداداتك في متغيرات البيئة الآمنة، لا في ملفات المصدر.
python -m uvicorn server.main:app --host 0.0.0.0 --port 8000 --workers 1
```

افتح `http://localhost:8000`. SQLite مخصص للتطوير؛ لا يُسمح بتفعيل الحسابات على Vercel دون PostgreSQL دائم.

ملف `.env.example` يشرح المتغيرات؛ التطبيق لا يقرأ `.env` تلقائيًا، فإعداد بيئة الاستضافة هو المرجع. يمكن استخدام مدير أسرار أو تمرير متغيرات البيئة من المنصة.

## ربط الذكاء الاصطناعي

### Gemini

اضبط `GEMINI_API_KEY` في إعدادات الخادم الآمنة. يستخدم الموصّل ترويسة `x-goog-api-key`، ولا يضع المفتاح في JavaScript.

بعد إنشاء مالك محليًا:

```bash
python -m server.manage create-owner owner@example.com
```

سجّل دخول المالك، وافتح لوحة التحكم ثم الإعدادات واضغط «اكتشاف نماذج Gemini». القائمة تُجلب من `/v1beta/models` وتُصفّى إلى نماذج توليد النصوص؛ لا تدّعي القائمة أن كل نموذج اجتاز اختبار جودة أو أنه يدعم كل أداة.

### ai-seek

اضبط `AISEEK_ACCESS_TOKEN` كمتغير خادم، لا في المصدر. يستخدم الموصّل:

```text
POST https://ai-seek.thebetter.ai/v4/chat/send
x-access-token: [provided securely by the hosting environment]
x-app-id: ai-seek
```

النماذج السبعة الواردة في كود المالك:

| العائلة | معرّف النموذج المرسل |
|---|---|
| DeepSeek | `deepseek/deepseek-chat` |
| Gemini | `google/gemini-2.5-flash-lite` |
| Qwen | `qwen/qwen3-32b` |
| Qwen Coder | `qwen/qwen-coder-32b` |
| Grok | `grok/grok-4-fast` |
| GPT | `openai/gpt-5-mini` |
| Claude | `anthropic/claude-3.5-sonnet` |

هذه أسماء مرشحة من تكامل المالك، وليست اكتشافًا شاملًا من المزوّد. لم يُقدَّم مسار موثق لسرد كل نماذج ai-seek، ويُظهر السجل حالتها بوصفها `provided-candidate` إلى أن يوجد دليل أفضل. نجاح استجابة طلب باسم معين لا يثبت وحده هوية النموذج البعيد إذا كانت الخدمة تستبدله داخليًا.

الخدمة تعرض SSE نصيًا، لا واجهة function calling أصلية. لذلك ينفّذ الموصّل بروتوكول JSON محددًا لطلبات الأدوات، ثم يتحقق الخادم من الأسماء والمدخلات والصلاحيات وينفذ الأدوات الحقيقية. الرد النثري المخالف للبروتوكول لا يُعامَل كتنفيذ.

تُنشأ معرفات جديدة للمحادثة والرسائل؛ لا يعاد استخدام المعرفات الثابتة أو بصمة جهاز Android المرفقة في العينة. تُحترم أخطاء صلاحيات الحساب، ولا توجد محاولة لتجاوز القيود أو انتحال اشتراك مدفوع.

### OpenAI-compatible اختياري

اضبط `OPENAI_API_KEY` و`OPENAI_BASE_URL` وأسماء `FAST_MODEL` و`STANDARD_MODEL` و`ADVANCED_MODEL`. لا تظهر أسماء مزودين غير موصولين بوصفها إمكانات متاحة.

| مهام وكيل يوميًا | 0 | 10 | 50 | 200 |

تُصفّر الحصص عند منتصف الليل UTC. البحث الخارجي يحتاج Pro أو Ultra واسترجاعًا موصولًا؛ يدعم Plus أدوات الملفات والحساب ومخططات المهام دون البحث الخارجي. الدفع الإلكتروني غير موصول، وتعيين الخطط محصور بالمالك. يمكن تعديل السياسة المركزية في `server/plans.py`؛ هذه حدود تشغيل، وليست أسعار اشتراك.

## التشغيل الآمن والنشر

- **Vercel:** ملفات `api/index.py` و`vercel.json` جاهزة لنشر الواجهة والخادم. يجب إضافة `DATABASE_URL` لقاعدة PostgreSQL دائمة ومفاتيح المزوّد في البيئة الآمنة. ترفض النسخة إنتاج حسابات وجلسات داخل SQLite مؤقت على serverless.
- **Docker / خادم دائم:** استخدم `Dockerfile`، واربط PostgreSQL ونسخًا احتياطية مُدارة. يعمل الخادم بعامل واحد؛ مهام الطلبات المحدودة ليست بديلًا عن طابور عمال مستقل لأعمال الساعات والأيام.
- **الاستمرارية:** PostgreSQL يحفظ الحسابات والمحادثات والملفات ونقاط الاستئناف. لا توجد قاعدة SQLite تجريبية أو حسابات QA في أرشيف الإصدار.
- **الأسرار:** لا توجد مفاتيح فعلية في المصدر. يجب تدوير أي مفتاح نُشر في المحادثة وإدخاله عبر قناة آمنة. بيانات اعتماد جلسة التطوير لا تُنسخ إلى Vercel ولا تُسوّق بوصفها أسرار إنتاج دائمة.
- **المالك:** لا يصبح أول مسجّل مالكًا تلقائيًا. استخدم أمر الإدارة على خادم مصرح به.
- **القيود الخارجية:** ai-seek خدمة طرف ثالث وتوفر نماذجها وصلاحياتها يخضعان لحساب المستخدم. لا يتضمن المشروع تجاوزًا لتلك الصلاحيات.

## الاختبارات

```bash
python -m pytest -q
node --check app/app.js
node --check app/agent-fx.js
```

اختبارات المزوّد تستعمل استجابات HTTP اصطناعية معلّمة بوضوح، لا نماذج وهمية في التطبيق الفعلي. وهي تثبت صحة مسار التكامل، لكنها لا تثبت صلاحية مفتاح حي أو جودة نموذج بعيد. تقرير التسليم يسجل نتيجة الاختبارات الحية بصورة منفصلة.

## حدود يجب عدم الخلط بينها وبين إمكانات مكتملة

- لا توجد صلاحية shell أو متصفح بعيد أو نشر ذاتي أو شراء أو مراسلة أو موصلات خارجية عامة؛ النظام يصرّح بعدم توفرها بدل محاكاتها.
- لا توجد عمال متعددة أو وكلاء مستقلون متوازون؛ السجل يصرّح بـ `parallel_agents=false`.
- توليد الصور وتحليل المرفقات غير موصولين بمزوّد فعلي بعد، ويرفضهما الخادم بوضوح.
- `validate_file` يفحص JSON/CSV أو بنية HTML الأساسية أو النص غير الفارغ. ليس اختبار متصفح أو مترجم أو ضمان صحة البرنامج.
- الاستئناف ممكن بعد إخفاق موثق أو انقطاع، لكنه يتوقف للمراجعة عندما يكون ناتج آخر استدعاء أداة غير آمن لإعادة التنفيذ.
- تقييمات التوجيه والانحدار قابلة للتكرار؛ لا توجد ادعاءات بتحسن الذكاء بنسبة عددية دون مقارنة نماذج حقيقية على مجموعة ثابتة.

انظر `docs/ARCHITECTURE.md` لتوزيع التحسينات على الطبقات، و`FLOWS.md` لقائمة تدفقات الواجهة وتغطية التحقق، و`docs/RELEASE-STATUS.md` لحالة التسليم والعوائق الفعلية وحدود الجاهزية للإنتاج.
